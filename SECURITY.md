# Security

## Reporting a problem

If you find a security issue in this project, please report it privately through GitHub's private vulnerability reporting (the "Report a vulnerability" button on the Security tab). Please don't open a public issue for security problems.

I'll acknowledge the report as soon as I can and keep you updated while it's fixed.

## Data in this repository

This repository contains only synthetic data or data from public sources. It contains no data from any employer, client or real environment. If you believe something here exposes real or sensitive information, please report it the same way.
